### 2.3 后台任务（`app_config.task_queue`）

源码：`app/shared/background_tasks.py`

| 参数 | 默认 | 含义 |
|------|------|------|
| `task_key_prefix` | `task:doc_parse:` | Redis 任务状态 key 前缀 |
| `task_ttl_seconds` | `86400`（24h） | 任务状态 TTL |

> ⚠️ **这不是分布式队列。** 任务协程跑在**当前进程**的事件循环里，Redis 只存状态、
> 不存待执行任务。因此：进程重启/崩溃 → 执行中的任务直接消失且不会自动续跑；
> 多副本部署时任务不会被分担；没有重试。
>
> 兜底措施：每条状态带 `worker_id`，进程启动时 `reconcile_orphaned_tasks()` 会把
> 其它 worker 遗留的 `pending`/`running` 记录改成 **`interrupted`**，
> 让孤儿任务成为可见的终态，而不是永远停在 `running`。
>
> 需要「重启后继续执行 / 跨副本分担 / 自动重试」，应换成 Redis Stream、ARQ 或 Celery。

**任务状态取值**：`pending` → `running` → `completed` / `failed` / `interrupted`

## 4. Redis：键结构与字段

### 4.1 短期记忆 STM

**前缀**：`{key_prefix}` = `agent:stm`（可配）

| Key | 类型 | 内容 |
|-----|------|------|
| `{prefix}:{tenant}:{user}:{session}:messages` | **ZSET** | member=MsgPack(+Zstd) 消息；score=毫秒时间 |

| `{prefix}:{tenant}:{user}:{session}:meta` | **STRING** | `SessionMeta` 序列化 |
| `{prefix}:{tenant}:{user}:{session}:lock` | **STRING** | 分布式写锁 |

**消息体 `MessageRecord`（逻辑字段）**

| 字段 | 类型 | 说明 |
|------|------|------|
| `message_id` | str | 唯一 ID |
| `role` | user/assistant/tool/system | 角色 |
| `content` | str | 正文 |
| `created_at` | int | 秒级时间戳 |
| `turn_index` | int | 轮次 |

**`SessionMeta`**

| 字段 | 说明 |
|------|------|
| `total_turns` | 总轮次 |
| `last_updated_at` | 最近更新 |
| `last_compressed_turn` | 上次压缩轮次 |

**`SessionSummary`**

| 字段 | 说明 |
|------|------|
| `content` | 压缩摘要文本 |
| `compressed_at` | 压缩时间 |
| `compressed_round` | 对应轮次 |

### 4.2 上传任务状态

## 7. 记忆优先级与数据流（配置如何生效）

| 优先级 | 数据源 | 关键配置 |
|--------|--------|----------|
| P0 | STM recent messages | `max_messages`、`ttl_seconds` |
| P1 | 用户画像 MySQL (+Redis 缓存) | `user_profile_cache_ttl` |
| P2 | STM summary | `compression.*` |
| P3 | LTM Milvus | `ltm.search.*`、去重阈值 |

写入 LTM：敏感 `sensitive_patterns` → 去重 `deduplication` → insert；命中 `update_on_hit`。

## 9. 调参建议（简表）

| 目标 | 优先改 |
|------|--------|
| 上下文太短/太长 | `stm.window.max_messages`、`compression.keep_recent_rounds` |
| 压缩太勤 | 增大 `trigger_rounds` / `trigger_messages` |
| LTM 噪声多 | 提高 `score_threshold`，降低 `top_k` |
| LTM 漏记 | 降低去重阈值或 top_k 检索 |
| 上传任务查不到 | 看 Redis `task:doc_parse:*` 与 `task_ttl_seconds` |
| 文档更新不生效 | MySQL `content_hash` 是否相同（幂等跳过）；Milvus `is_deleted`/`version` |
| 口语检索差 | 确认 `rag_rewrite.formalize_enabled=true`、超时是否过短 |
| 库名搞混 | LTM=`customer_agent_long_memory`；RAG=`rag_documents` |
