## 5. 智能问答主链路（SSE）

```mermaid
sequenceDiagram
    autonumber
    participant C as 客户端
    participant API as api/langgraph
    participant AQS as agent_query_service
    participant G as LangGraph graph
    participant LLM as LLM
    participant MM as MemoryMiddleware
    participant RD as Redis
    participant NJ as Neo4j
    participant MV as Milvus
    participant MY as MySQL

    C->>API: POST /api/langgraph/query<br/>query,user_id,conversation_id?
    API->>API: thread_id = conversation_id or uuid4()
    API->>AQS: stream_agent_query(...)
    AQS->>G: astream(InputState, stream_mode=messages,<br/>configurable{thread_id,user_id})

    G->>LLM: Router 结构化输出
    alt type=general
        G->>MM: load_memory / before_agent
        MM->>RD: STM
        MM->>MY: 画像(可走缓存)
        MM->>MV: LTM hybrid
        G->>LLM: general 回复
    else type=rag_doc-query
        G->>LLM: Guardrails
        alt 拒答
            G-->>API: 固定拒答 AIMessage
        else continue
            G->>LLM: RetrievalPlan
            G->>MM: enrich_question ← before_agent
            alt GRAPH / RAG / PARALLEL / THEN
                G->>NJ: KG search (可选)
                G->>MV: RAG search (可选)
                G->>LLM: 摘要生成
            else AGENT_REACT
                loop 最多 max_attempts
                    G->>LLM: ReAct + tools
                    G->>NJ: tool neo4j_query
                    G->>MV: tool rag_search
                    G->>LLM: 充分性判断
                end
            end
        end
    end

    Note over API,C: StreamingResponse 创建时即带 Header X-Conversation-ID

    loop 每个 token/片段
        G-->>API: (chunk, metadata)
        API->>API: 过滤 tool_calls / research_plan / 空 content
        API-->>C: data: "文本"\n\n
    end

    G->>MM: after_response → after_agent
    MM->>RD: 写消息 / 可能压缩
    MM->>MV: 可能写 LTM
    MM->>MY: 可能更新画像
```

## 8. 检索执行（能力标签→路径）执行策略

> 计划节点输出的是 **能力标签**，不是互斥五选一。  
> `resolve_execution_plan`：multi_hop→REACT；仅图→GRAPH_ONLY；仅文档→RAG_ONLY；  
> 两侧+sequential→GRAPH_THEN_RAG；两侧+parallel→PARALLEL；都 false→REACT。

```mermaid
flowchart TB
    TAGS[能力标签<br/>need_graph / need_rag<br/>mode / complexity] --> RES[resolve_execution_plan]
    RES --> RP[resolved_plan]
    RP --> S1
    RP --> S2
    RP --> S3
    RP --> S4
    RP --> S5

    subgraph S1["GRAPH_ONLY = 仅 need_graph"]
        A1[get_retriever kg]
        A1 -->|None| F1[no_neo4j_response]
        A1 -->|OK| P1[Pipeline.execute_single kg]
    end

    subgraph S2["RAG_ONLY = 仅 need_rag"]
        A2[get_retriever rag]
        A2 -->|None| F2[文档检索暂不可用]
        A2 -->|OK| P2[Pipeline.execute_single rag]
    end

    subgraph S3["PARALLEL = both + parallel"]
        A3[get kg + rag]
        A3 --> G3[asyncio.gather]
        G3 --> K3[kg: graph_only_query]
        G3 --> R3[rag: rag_only_query]
        K3 --> M3[merge records]
        R3 --> M3
        M3 --> SUM3[summarize]
    end

    subgraph S4["GRAPH_THEN_RAG = both + sequential"]
        A4[get kg + rag]
        A4 --> K4[先 kg.search 原 query]
        K4 --> Q4[build_graph_then_rag_query<br/>拼入 kg records]
        Q4 --> R4[rag.search]
        K4 --> M4[merge]
        R4 --> M4
        M4 --> SUM4[summarize]
    end

    subgraph S5["AGENT_REACT = multi_hop 或兜底"]
        A5[execute_react 见第10节]
    end
```

## 10. ReAct 子图完整循环

```mermaid
flowchart TD
    START([execute_react]) --> NJ{get_neo4j_graph?}
    NJ -->|None| FAIL[no_neo4j_response]
    NJ -->|OK| EQ[enrich_question]
    EQ --> SG[get_react_subgraph<br/>容器单例缓存]
    SG --> BUILD[若未构建: create_react_agent]
    BUILD --> TOOLS[tools: neo4j_query + rag_search]
    TOOLS --> LOOP

    subgraph LOOP["外循环 attempt = 1..max_attempts 默认5"]
        INV[子图 ainvoke<br/>recursion_limit 默认11]
        INV --> STEP{输出含<br/>need more steps?}
        STEP -->|是| RETRY1[记录 step_exhausted_reason<br/>continue]
        STEP -->|否| JUDGE[react_judge_model<br/>ReactAnswerCheckOutput]
        JUDGE --> D{decision}
        D -->|sufficient| OK[返回最终答案 messages]
        D -->|retry| RETRY2[附加 retry_prompt 再试]
        D -->|handoff| FB1[准备 fallback]
        RETRY1 --> INV
        RETRY2 --> INV
    end

    LOOP -->|用尽 attempts| FB[fallback_answer<br/>亲～这个问题回答不了哦～]
    OK --> AFTER([回到 after_response])
    FB --> AFTER
    FB1 --> AFTER
    FAIL --> AFTER
```

## 12. 记忆压缩与抽取

```mermaid
flowchart TD
    META[SessionMeta] --> CHK{should_compress?}
    CHK -->|total_turns 间隔 ≥ trigger_rounds<br/>或 消息数 ≥ trigger_messages| YES[开始压缩]
    CHK -->|否| SKIP[跳过]

    YES --> OLD[取出较旧消息]
    OLD --> LLM[summary_compressor = MemoryExtractor.LLM]
    LLM --> SUM[SessionSummary.content]
    SUM --> KEEP[保留 keep_recent_rounds 最近轮]
    KEEP --> SAVE[写回 summary + 裁剪 messages]

    SAVE --> EXT[extractor.extract<br/>user, assistant, summary]
    EXT --> SEM[语义记忆列表]
    EXT --> PROF[UserProfileData]
```

```mermaid
sequenceDiagram
```

```mermaid
            IS->>DP: parse_document

            JOB->>DOC: apply_indexing_result ready|failed
            TQ->>RD: completed + result

            RD-->>C: pending/running/completed/failed
        end
    end
```
