### 五个薄弱点修复摘要

| 薄弱点 | 修复方案 | 关键机制 |
|--------|---------|---------|
| 1. 异常吞没 | TurnMemoryReport + turn_view_status + handler 决定重试 | 全部 completed→mark_completed, 任一 failed→向上抛 |
| 2. 压缩无幂等键 | compression_id + compression_tasks 表 | SHA256(session:from:to) + ON DUPLICATE KEY UPDATE |
| 3. 画像无事件级幂等 | source_turn_id + uk_user_fact_source | 同 (user, key, turn) 只有首次 INSERT 成功 |
| 4. hit_count 非幂等 | update_memory_hit_infos_deduped + memory_hit_events | (turn_id, memory_id) 唯一索引去重 |
| 5. fire-and-forget 不可观测 | _fallback_counter + 日志 | get_fallback_metrics() 导出 |
