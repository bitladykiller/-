### 五个薄弱点修复摘要

| 薄弱点 | 修复方案 | 关键机制 |
|--------|---------|---------|
| 1. 异常吞没 | TurnMemoryReport + turn_view_status + handler 决定重试 | 全部 completed→mark_completed, 任一 failed→向上抛 |
| 2. 压缩无幂等键 | compression_id + compression_tasks 表 | SHA256(session:from:to) + ON DUPLICATE KEY UPDATE |
| 3. 画像无事件级幂等 | source_turn_id + uk_user_fact_source | 同 (user, key, turn) 只有首次 INSERT 成功 |
| 4. hit_count 非幂等 | update_memory_hit_infos_deduped + memory_hit_events | (turn_id, memory_id) 唯一索引去重 |
| 5. fire-and-forget 不可观测 | _fallback_counter + 日志 | get_fallback_metrics() 导出 |

### LTM 接入

为 MemorySearchResult 列表传给 after_agent，打通命中统计主链路。

## v3.36 检视修复 (commit 6982efa)

对 commit 0afe521 做代码检视，发现并修复 4 个缺陷 + 文档勘误：

1. **[严重] LTM hit_count 覆盖**: event payload 重建的 LongTermMemory 对象 hit_count=0,
   partial upsert 会把 Milvus 中的真实计数覆盖为 1。新增 `_reload_hit_counts` 方法
   从 Milvus 读出真实值后再递增。
2. **[中等] compression_tasks from_turn/to_turn 硬编码为 0**: 改为从调用方传入
   `meta.last_compressed_turn` 和 `meta.total_turns`。
3. **[中等] COMPRESSION 视图状态恒为 COMPLETED**: 应区分 should_compress=False
   (SKIPPED) 和 ltm_enabled=False (LTM/PROFILE=SKIPPED) 两个分支。
4. **[回归] ltm_saved_count=0 误删**: 检视编辑时意外移除初始化，恢复之。

**遗留（非本次引入）**: `uk_user_fact(user_id, fact_key)` 唯一约束与画像版本化逻辑
冲突——版本化 deactivate 旧行再 insert 新行会违反约束。待后续处理。
